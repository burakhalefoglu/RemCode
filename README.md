# 🔗📱 RemLinkAgent
### Mobile CLI Agent for Z.AI, Qwen & Kimi | Multi-Model, BYOK

> **"Your terminal, in your pocket. Your models, your rules."**

RemLinkAgent is an open-source mobile agent that links your local terminal to your mobile device via a secure QR-code pairing. It is purpose-built for the cost-effective and powerful Chinese AI ecosystem (Z.AI, Qwen, and Kimi) — with a Bring-Your-Own-Key (BYOK) model where AI requests flow directly from your machine to your provider. We never touch your traffic or your keys.

Say goodbye to expensive Claude/OpenAI API bills and desktop-bound workflows. With RemLinkAgent, you can chat with your code, **hot-swap between AI models mid-conversation**, and approve dangerous commands — directly from your phone.

## 🚀 Key Features

### 📱 Multi-Model Chat with Hot-Swapping (BYOK)
Use Z.AI, Qwen, and Kimi **in the same chat session**.
- **Hot-Swapping:** Change the AI model mid-chat from your phone's dropdown — the conversation context is preserved.
- **Zero AI Markup:** You bring your own API keys. AI requests flow directly from your machine to the provider. We never touch your traffic.

### 📱 Secure QR-Code Pairing
Pair your phone with your terminal in seconds. Scan a QR code generated by the CLI (`rla connect`), and your terminal is mirrored and controllable from your mobile device over a secure WebSocket (WSS) connection.

### 📱 Zero-Loss Background Continuity
If you close the app, lose Wi-Fi, or switch to cellular, your local CLI agent **keeps working**. Powered by **NATS JetStream**, when you reopen the app, it syncs from the exact sequence number it left off. No lost code, no broken sessions.

### 📱 Dangerous Command Approval
When the AI proposes a potentially destructive shell command, the pipeline pauses and sends a push notification to your phone. Review the command, then approve or reject it — no surprises.

## 🏗️ Architecture

> **Zero-Touch AI:** AI requests NEVER pass through the server — they flow directly from the CLI to your provider. The server only orchestrates sessions, events, and push notifications. The "Link" in RemLinkAgent is the connection between your terminal and your phone — not a middleman for your AI traffic.

| Layer | Technology | Description |
| :--- | :--- | :--- |
| **CLI Agent** | Go | Single static binary, < 30MB RAM, cross-compiled for all OSs. |
| **Server Backend** | Go | WebSocket gateway, NATS integration, session orchestration. |
| **Message Queue** | NATS + JetStream | Persistent, replayable streams for background sync. |
| **Database** | SQLite | Zero-config, stores sessions and devices. |
| **Mobile App** | Flutter | Single codebase for iOS and Android. |

## ⚡ Getting Started

> **Status:** RemLinkAgent is under active development. The CLI, server, and mobile app are being built now. Installation instructions will be published with the first release.

### 1. 📱 Install the CLI Agent
Install the RemLinkAgent CLI on your local machine (macOS, Linux, or Windows).
```bash
curl -sSL https://remlinkagent.com/install | sh
```

### 2. Authenticate (BYOK)
Log in with your own API keys. Keys are encrypted securely in your OS keychain.
```bash
rla login
# Prompt: Enter your Z.AI API Key:
# Prompt: Enter your Qwen API Key (optional):
# Prompt: Enter your Kimi API Key (optional):
```

### 3. Connect Your Mobile Device
Initialize the secure QR-code pairing.
```bash
rla connect
```
Scan the QR code with the **RemLinkAgent mobile app**. Your terminal is now linked and controllable from your phone.

## 🛠️ Core Commands

*   `rla login` — Store your AI provider API keys locally (encrypted).
*   `rla connect` — Generate a QR code to pair your mobile device.
*   `rla status` — Check CLI daemon, server connection, and paired devices.
